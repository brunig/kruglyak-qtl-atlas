# Inventory: Brem and Kruglyak 2005 (PNAS 102:1572) sources

Generated by `ingest/inventory.py` from `sources/brem2005pnas/raw/`. The article is read from its PubMed Central page,
saved as `sources/brem2005pnas/article.html` (https://pmc.ncbi.nlm.nih.gov/articles/PMC547855/, fetched 2026-11-02 with a
plain request). www.pnas.org is not reachable from the build environment.
PMC serves the article PDF and the four supplementary files (pnas_102_5_1572__.html, __1.html, __2.pdf, __3.pdf) only
behind a JavaScript proof-of-work page; a plain request returns the challenge page, and solving it would be bot-check
circumvention, so those files are not in the bundle. NCBI E-utilities efetch (db=pmc) returns front matter only: the
publisher does not allow full-text XML. That response is kept in raw/ as a record.
Statements and the two tables the ingest uses are extracted verbatim from article.html into `extracted/text_facts.tsv`
and `extracted/tables.tsv` by `extracted/extract.py`. Checksums are in `MANIFEST.tsv`.

Spreadsheets and text tables are summarised sheet by sheet: dimensions (rows x columns, including the
header row), column names, and the first three data rows. Values over 60 characters are cut.
